## 📘 README — Yoga4U Wellness Centre Web Application

---

# 🧘‍♀️ Yoga4U Wellness Centre

A full-stack **Yoga & Wellness Management Web Application** designed for Yoga4U Wellness Centre. The platform provides yoga class information, wellness events, community posts, authentication, and interactive wellness features.

---

# 🚀 Tech Stack

## 🖥️ Frontend

* React.js (Vite)
* React Router DOM
* Axios (API communication)
* Tailwind CSS (UI styling)
* Lucide React (icons)
* Context API (authentication state management)

---

## ⚙️ Backend

* Node.js
* Express.js
* MongoDB (Mongoose ODM)
* JWT Authentication (Login/Register security)
* Bcrypt.js (password hashing)
* CORS & dotenv configuration

---

# 🎯 Core Features

## 🔐 Authentication System

* User Registration (name, email, password)
* Secure Login with JWT
* Protected routes using auth context
* Token-based session management
